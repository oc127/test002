# 嘻哈 MV - 夜店 Drop 瞬间

**风格**: Hip-Hop / Trap
**BPM 参考**: 140
**镜头构成**: Performance 50% + Conceptual 30% + Narrative 20%

## 核心概念

说唱歌手站在夜店舞台中央，drop 瞬间激光爆发，周围人群涌动

## 分镜

```
[0-2s]   Performance    歌手低角度仰拍特写：金链子摆动、嘴型说唱
[2-4s]   Narrative      夜店全景：人群、DJ 台、激光扫射
[4-6s]   Conceptual     慢动作特写：子弹时间般的气息喷出 + 光粒子爆炸
[6-8s]   Performance    歌手走向镜头，camera tracks back
[8-10s]  Drop Climax    爆炸瞬间：多重曝光 + 色彩爆发 + 人群手高举
```

## 后期剪辑建议

- **BPM 140 切镜**：每 0.4-0.5 秒（即每拍）切一次
- **Drop 处**：持续 1 拍（0.4s）的"定格 + 色彩爆发"
- **加字幕**：歌词可以同步闪现（hip-hop MV 常见手法）
- **调色**：高对比、低中间调，阴影偏青

## A/B 变体

- **v2 极简版**：全程只用 performance 镜头，不要 conceptual
- **v3 街头版**：场景从夜店改成街头，更 Travis Scott
- **v4 舞蹈版**：加舞者 + 编舞，偏 K-pop hip-hop
