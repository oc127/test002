# 12 种 2 秒钩子公式

前 2 秒决定视频生死。这是经过验证的 12 种爆款钩子公式，按场景挑。

---

## 1. 痛点钩子 (Pain Point)

**公式**：直接把用户最痛的场景拍出来

**例子**：
- 熬夜党：凌晨 3 点黑眼圈的镜子特写
- 妈妈人群：孩子乱跑、玩具散一地
- 学生党：堆积如山的考试资料
- 上班族：地铁里被挤成肉饼

**适用**：日用品、工具、家居、母婴
**AI 视频 Prompt 写法**：
```
Extreme close-up of [痛点具象画面]. Handheld camera, harsh realistic lighting,
documentary style, no glamour, raw and uncomfortable feel.
```

---

## 2. 悬念钩子 (Mystery)

**公式**：让观众好奇"这是什么/为什么/接下来发生什么"

**例子**：
- 一只手缓缓撕开密封袋，**但袋子里是什么不露**
- 有人对着镜子说"我不想让别人知道……"
- 一扇门缓缓打开，**门后画面在 3 秒后才揭示**

**适用**：新奇特、美妆、护肤、黑科技
**AI Prompt 写法**：
```
Close-up of a hand slowly peeling open a sealed package, but the contents
are obscured. Slow motion, tension building, cinematic lighting.
```

---

## 3. 反差钩子 (Contrast)

**公式**：打破观众预期，形成视觉或概念冲突

**例子**：
- 穿西装的男人在跳街舞
- 老奶奶在玩电竞
- 破旧老屋里摆着超现代家具
- "这是我的早餐"——展示一碗泥巴（然后揭示是巧克力）

**适用**：几乎所有品类，尤其是反传统认知的产品
**AI Prompt 写法**：
```
[反差场景] — [期待的元素] but [打破期待的元素].
Bright sharp lighting, crisp focus on the unexpected element.
```

---

## 4. 数字钩子 (Number)

**公式**：用具体数字制造冲击感

**例子**：
- "10 秒穿好的西装，价格不到 100"
- "1 天卖 10 万单的秘密"
- "用了 30 年的老办法，90% 的人不知道"
- "99% 人忽略的小技巧"

**适用**：知识付费、工具、教程类
**AI Prompt 写法**：钩子通常是文案主导，画面上配数字大字幕 + 产品特写
```
Bold large text overlay showing "[数字]" dominating the screen,
product in background, dramatic lighting, punchy visual rhythm.
```

---

## 5. 对比钩子 (Before/After)

**公式**：直接把"用前 vs 用后"剪在前 2 秒

**例子**：
- 一半脸化妆一半不化
- 一半头发毛躁一半柔顺
- 桌面一半凌乱一半整齐

**适用**：美妆、护肤、清洁、收纳、家居
**AI Prompt 写法**：
```
Split screen composition: left side shows [使用前状态],
right side shows [使用后状态]. Same person, same lighting,
clear visual difference.
```

---

## 6. UGC 钩子 (Authentic / Real Person)

**公式**：真人对镜头说话，像分享日常不像广告

**例子**：
- "姐妹！这个真的太绝了……"
- "没想到我这种懒人也能……"
- "我昨天买了这个，结果……"

**适用**：小红书、抖音、种草向
**AI Prompt 写法**（Kling / Runway 更擅长）：
```
Handheld vlog-style shot, young woman speaking directly to camera,
slightly off-center framing, natural daylight, authentic bedroom setting,
casual messy hair, smartphone selfie video aesthetic.
```

---

## 7. 极限测试钩子 (Extreme Test)

**公式**：把产品暴力对待，测试极限性能

**例子**：
- 把手机从 10 米高摔下来
- 把羽绒服浸水后看保暖效果
- 用锤子砸 iPad 膜

**适用**：3C、硬件、工具、户外装备
**AI Prompt 写法**：
```
Slow motion close-up of [产品] being [极限动作 e.g. dropped from height /
submerged in water]. High speed camera, dramatic lighting, impact moment frozen.
```

---

## 8. ASMR / 声音钩子 (Sensory)

**公式**：极致感官刺激——撕、切、捏、挤、爆

**例子**：
- 切开吐司看到拉丝芝士
- 挤黑头挤出长长一条（慎用，平台限流）
- 捏泡泡纸的满足感
- 巧克力裂开的瞬间

**适用**：食品、美妆、减压玩具
**AI Prompt 写法**：
```
Macro close-up slow motion of [物体] being [动作 e.g. cut / sliced / squeezed],
extreme detail, clean white studio background, crisp sharp lighting,
tactile texture visible.
```

---

## 9. 反向钩子 / 劝退 (Reverse)

**公式**："这个产品千万别买如果你是……"

**例子**：
- "这款面霜千万别买，除非你……"
- "别乱试这个，可能会……"
- "99% 的人不适合这个"

**适用**：所有品类，尤其小众爆品
**为什么有效**：逆向心理，越劝退越好奇
**AI Prompt 写法**：画面配合文案，通常是"产品特写+警告字幕"

---

## 10. 场景沉浸钩子 (Immersive Scene)

**公式**：直接把观众拉进特定场景

**例子**：
- 冬天早上 6 点，从热被窝伸出手，窗外大雪
- 雨天回家，湿透的鞋子和手里的外卖
- 加班到 11 点，泡面在桌上冒热气

**适用**：场景化强的产品（咖啡、家居服、速食）
**AI Prompt 写法**：
```
First-person POV, [具体时间] [具体环境], [具体感官细节 e.g. steam rising,
rain streaks on window]. Atmospheric, intimate, cinematic depth of field.
```

---

## 11. 专家 / 权威钩子 (Authority)

**公式**：专家/行业人士说话

**例子**：
- "作为皮肤科医生，我不推荐……"
- "10 年数码编辑，告诉你这款手机……"
- 白大褂 + 实验室背景

**适用**：医美、健康、教育、数码
**AI Prompt 写法**：
```
Medium shot of a person in [专业服装] in a [专业场景 e.g. clinic / laboratory /
studio], speaking directly to camera with authoritative posture.
```

---

## 12. 时效 / 稀缺钩子 (Urgency)

**公式**：制造紧迫感和稀缺感

**例子**：
- "今晚 12 点下架"
- "最后 100 件"
- "3 分钟后恢复原价"

**适用**：促销、直播切片
**AI Prompt 写法**：倒计时视觉 + 产品特写
```
Countdown timer overlay, "[时间]" prominently displayed,
urgent red color scheme, product prominently in frame.
```

---

## 钩子选择决策树

```
目标用户特征明显？  →  用【痛点钩子】或【UGC 钩子】
产品有极致性能？    →  用【极限测试钩子】
产品有视觉魔法？    →  用【反差钩子】或【ASMR 钩子】
品类竞争激烈？      →  用【反向钩子】或【悬念钩子】
做促销活动？        →  用【时效钩子】或【数字钩子】
权威品类（医美）？  →  用【专家钩子】
场景感强的产品？    →  用【场景沉浸钩子】
```

---

## 钩子 × 平台适配

| 平台 | 最有效钩子 | 慎用钩子 |
|------|-----------|---------|
| 抖音 | 痛点、反差、ASMR、极限测试 | 专家（太正经） |
| 小红书 | UGC、场景、对比 | 极限测试（太暴力） |
| Reels/TikTok 海外 | 反差、悬念、数字 | 反向（文化差异） |
| YouTube Shorts | 数字、专家、悬念 | UGC（需要质感） |

---

## 常见错误

1. **开头自报家门**：❌ "大家好我是..." → ✅ 直接上钩子
2. **口播 3 秒才进主题**：观众已经划走了
3. **钩子和产品无关**：标题党，但转化率惨
4. **钩子太刺激偏离品牌**：对品牌调性有害
5. **所有视频用同一个钩子**：应该 A/B 测试多种
