# 产品展示镜头模板

电商视频的中段（5-12 秒）是"卖点展示"。必须用专业的产品镜头语言，否则跟竞品视频长一样。

---

## A. 10 种必学的产品镜头

### 1. Hero Shot 主视觉
- **定义**：产品居中，最美的角度，纯净背景
- **用途**：产品登场、封面帧
- **Prompt**：
  ```
  Hero shot of [product] centered on a clean [colored] background,
  studio lighting from 45 degrees, subtle reflection underneath,
  product at its most flattering angle.
  ```

### 2. Macro Close-up 微距特写
- **定义**：极近距离展示材质细节（纹理、做工、工艺）
- **用途**：强调质感、工艺
- **Prompt**：
  ```
  Extreme macro close-up of [product detail - fabric weave / stitching /
  metal polish / surface texture], shot with 100mm macro lens,
  shallow depth of field, crisp studio lighting.
  ```

### 3. 360° Rotation 环绕旋转
- **定义**：产品旋转一周，展示全方位
- **用途**：立体感、细节全展示
- **Prompt**：
  ```
  [Product] rotating 360 degrees on a turntable,
  clean white background, even soft lighting,
  seamless rotation.
  ```

### 4. Exploded View 爆炸图
- **定义**：产品各部件分离漂浮，展示内部结构
- **用途**：科技感、展示技术
- **Prompt**：
  ```
  Exploded view of [product], all components floating in space
  separated, revealing internal structure, gray studio background,
  technical diagram aesthetic.
  ```

### 5. In-Use Shot 使用场景
- **定义**：真实使用场景，人+产品
- **用途**：场景化、代入感
- **Prompt**：
  ```
  [具体场景 e.g. morning kitchen / evening bedroom] where a [人物描述]
  is using [product] naturally, [具体动作], cinematic daylight,
  authentic lifestyle feel.
  ```

### 6. Before/After 前后对比
- **定义**：使用前 vs 使用后的直接对比
- **用途**：效果展示
- **Prompt（并排模式）**：
  ```
  Split screen comparison: left side "before" showing [问题状态],
  right side "after" showing [改善状态]. Same scene, same lighting,
  only the [relevant element] changes.
  ```
- **Prompt（时间线模式）**：
  ```
  Time-lapse transition from [问题状态] to [改善状态],
  shows the transformation process, [时长] compression.
  ```

### 7. Unboxing 开箱
- **定义**：手部特写打开包装
- **用途**：仪式感、礼盒感、高端调性
- **Prompt**：
  ```
  Overhead close-up of hands carefully opening a premium [color] box,
  revealing [product] nestled inside, soft natural daylight,
  tactile material textures, ASMR aesthetic.
  ```

### 8. Stress Test 抗压测试
- **定义**：产品承受极限条件
- **用途**：耐用性、性能展示
- **Prompt**：
  ```
  Slow motion close-up of [product] being [subjected to stress],
  dramatic lighting, impact moment frozen mid-action,
  frame rate 240fps capture feel.
  ```

### 9. ASMR Detail ASMR 细节
- **定义**：触感/声音强的瞬间（挤出、切开、拉丝）
- **用途**：食品、美妆、减压
- **Prompt**：
  ```
  Macro slow motion of [material] being [action - squeezed / cut /
  stretched], revealing [texture], crisp sound cues, pure white
  background, clinical studio lighting.
  ```

### 10. Hand Model 手部演示
- **定义**：手部拿着/操作产品
- **用途**：尺寸感、操作流程
- **Prompt**：
  ```
  Close-up of well-manicured hands holding/operating [product],
  neutral background out of focus, product clearly in focus,
  warm soft daylight.
  ```

## B. 品类 × 必用镜头

| 品类 | 必须有的镜头 |
|------|------------|
| **美妆护肤** | Hero + Macro(质地) + In-Use(上脸) + Before/After |
| **食品** | ASMR(拉丝/切开) + Macro(食材) + 吃播(人物反应) |
| **服饰** | In-Use(穿着) + 360°旋转 + Macro(面料细节) |
| **3C 数码** | Hero + Exploded View + Stress Test + 功能演示 |
| **家居** | Before/After(空间改造) + In-Use + Hero |
| **工具** | Stress Test + In-Use + Hand Model |
| **母婴** | In-Use(宝宝) + Safety Test + Macro(材质) |
| **户外装备** | Stress Test(防水/抗摔) + In-Use(真实环境) |

---

## C. 背景/环境选择

### 1. Studio White 纯白背景
- **用途**：Hero Shot、淘宝主图感
- **注意**：显廉价，高端产品慎用

### 2. Colored Paper 纯色背景
- **用途**：品牌调性、社媒友好
- **技巧**：用品牌色，或互补色

### 3. Marble / Stone 大理石/石材
- **用途**：高端感、美妆、珠宝
- **Prompt 关键词**：`white marble surface with subtle gray veining`

### 4. Wooden 木质
- **用途**：自然、食品、家居
- **Prompt 关键词**：`warm oak wooden surface`

### 5. Lifestyle Scene 生活场景
- **用途**：In-Use 镜头的背景
- **技巧**：选不抢戏的场景（书房、厨房一角）

### 6. Dark Moody 暗调
- **用途**：高端、科技、手表、白酒
- **Prompt 关键词**：`dark moody background with dramatic side lighting`

## D. 光线方案

| 光线 | 适用品类 | Prompt |
|------|---------|--------|
| 柔和散射 | 美妆、母婴、食品 | `soft diffused lighting, like a cloudy window` |
| 硬光侧光 | 3C、手表、酒 | `hard key light from 45 degrees, sharp shadows` |
| 顶部柔光箱 | 食品、美妆 | `overhead softbox, even top-down lighting` |
| 逆光勾边 | 饮料、透明物 | `backlight creating a glowing rim, subject in silhouette` |
| 自然阳光 | 生活方式、户外 | `natural golden hour sunlight through window` |
| 彩色霓虹 | 潮牌、科技 | `colored gel lights, pink and cyan accents` |

## E. 典型问题

### 1. "产品看起来没质感"
- ❌ 只用平光
- ✅ 用侧光 + 柔光箱，制造明暗层次
- ✅ 加反光板或反光元素

### 2. "产品跟别家长一样"
- ❌ 用模板化的白底展示
- ✅ 选一个"品牌专属"的背景（颜色/材质）

### 3. "宝宝画面和产品不连接"
- ❌ 先展示宝宝，再切产品（两个独立画面）
- ✅ 宝宝和产品在同一镜头（宝宝拿着/碰着产品）

### 4. "Before/After 不可信"
- ❌ 光照不一样、角度不一样
- ✅ 锁定机位、锁定光源，只换产品状态

## F. 完整电商视频的镜头表（15 秒示例）

产品：一款便携咖啡机

```
[0-2s]   ASMR 钩子     蒸汽缓缓升起，深棕色液体滴落到透明杯中
[2-5s]   痛点          办公桌上乱糟糟，一个疲惫脸色
[5-8s]   方案 Hero     产品登场，纯白背景 + 柔光，品牌 Logo 露出
[8-11s]  In-Use        女生在办公室按一下按钮，咖啡 15 秒做好
[11-13s] Macro 细节    特写按钮质感 + 萃取过程的液体流动
[13-15s] CTA           产品 + "点击下方链接" + 手机屏幕截图
```
