# 电商广告视频生成 (E-commerce Video)

**电商视频 ≠ 电影视频**。核心差异：
- 电影视频追求"艺术感染力"
- 电商视频追求"**转化率**"——前 2 秒留存、中间讲清卖点、结尾让人买

## 调用时机

**强触发词**：
- 带货 / 电商 / 产品广告 / 商品视频
- 2 秒钩子 / 抖音电商 / 直播切片
- 卖点展示 / 爆品 / 种草
- product ad / commercial / TikTok ad

**典型请求**：
- "帮我给这款蓝牙耳机做 5 条不同钩子的 15 秒短视频"
- "做一个针对学生党的护肤品电商视频"
- "我的产品是折叠伞，帮我写 Runway 能用的 prompt"

## 工作流

1. **提取产品信息** → 品类、核心卖点、目标人群、使用场景
2. **选钩子公式** → [`references/hook-formulas.md`](references/hook-formulas.md)
3. **设计产品展示** → [`references/product-shot-templates.md`](references/product-shot-templates.md)
4. **AIDA 结构填充** → Attention / Interest / Desire / Action
5. **适配目标模型** → [`references/model-adapters.md`](references/model-adapters.md)

## 电商视频的黄金结构

### 15 秒带货公式（最通用）

```
[0-2s]   钩子 Hook        → 冲突/悬念/反差，目的只有一个：别让手指划走
[2-5s]   痛点 Pain        → 目标用户的烦恼，引发共鸣
[5-9s]   方案 Solution    → 产品登场，一句话讲清解决了什么
[9-13s]  证据 Evidence    → 数据/对比/使用效果/UGC 截图
[13-15s] 行动 Action      → "点小黄车"/"评论区下单"/"立即购买"
```

### 6 秒短版（适合信息流广告）

```
[0-1.5s]  钩子
[1.5-4s]  方案（跳过痛点，直接展示产品魔法）
[4-6s]    CTA
```

### 30 秒剧情版（品牌向 + 带货）

```
[0-3s]    钩子
[3-10s]   剧情冲突
[10-18s]  产品登场 + 使用过程
[18-25s]  效果对比
[25-30s]  品牌 + CTA
```

## 4 个电商视频铁律

### 铁律 1：前 2 秒不要"铺垫"
- ❌ "很多人都有这个困扰……"（空话，没信息量）
- ✅ 直接上冲突画面：湿漉漉的头发、拥挤的地铁、塌方的眼袋

### 铁律 2：每 1.5-2 秒必须有视觉变化
手机刷视频的注意力窗口只有 1-2 秒。画面不变 = 流失。

### 铁律 3：产品特写至少占 3 秒
不展示产品细节 = 观众记不住品牌 = 不会下单。

### 铁律 4：一个视频只推一个卖点
多卖点 = 观众记住 0 个。分别做 5 条不同卖点的视频，胜过 1 条堆料的。

## 品类 → 结构映射

| 品类 | 推荐结构 | 钩子类型 |
|------|---------|---------|
| 美妆护肤 | 前后对比 + 使用特写 | 效果反差、肤况痛点 |
| 数码 3C | 痛点 + 功能演示 + 参数数据 | 速度/性能对比 |
| 服饰 | 换装混剪 + 场景穿搭 | 身材显瘦、搭配技巧 |
| 食品 | ASMR 声效 + 制作过程 + 吃播 | 流口水画面、拉丝特写 |
| 家居 | 使用场景 + 前后对比 | 空间改造、生活痛点 |
| 母婴 | 宝宝反应 + 父母使用感受 | 安全隐患、省心程度 |
| 工具/硬件 | 极限测试 + 对比 | 破坏性测试、力学反差 |

## 平台适配

### 抖音 / 快手 / TikTok
- **比例**：9:16 竖屏
- **时长**：15s 最优，7-21s 可接受
- **字幕**：必须有，80% 用户静音看
- **开头**：首帧要能作为封面

### Instagram Reels
- **比例**：9:16
- **时长**：15-30s
- **风格**：更偏品牌美学，不像抖音那么粗暴

### YouTube Shorts
- **比例**：9:16
- **时长**：30-60s
- **风格**：允许更长叙事，可以"剧情+带货"

### 小红书
- **比例**：3:4 或 9:16
- **时长**：30-60s
- **风格**：UGC 感、去广告化、"姐妹安利"调性
