# 叙事框架库

AI 视频短片（10-60 秒）能用的叙事结构。按时长选框架，不是按主题选。

---

## 1. 5 段式（默认推荐，10-15 秒短片通用）

最稳的骨架。对应观众注意力曲线。

| 段落 | 时长占比 | 目的 | 镜头建议 |
|------|---------|------|---------|
| **Hook 钩子** | 15% | 抓住眼球，1.5-2 秒决定观众留不留 | 最强视觉冲击、反差、速度 |
| **Setup 建立** | 25% | 交代主体是谁、在哪、要干什么 | 中景或近景，相对稳定 |
| **Rising 推进** | 25% | 升级紧张感/美感/情绪 | 运镜加速、角度变化 |
| **Climax 高潮** | 25% | 最贵最炸的画面 | 大动作、慢动作、特效 |
| **Payoff 收尾** | 10% | 余韵 / 悬念 / Call back | 定格 / 拉远 / 淡出 |

**10 秒示例**（赛博朋克女杀手）：
```
[0-1.5s]  Hook      机械义肢特写，红光在手掌电路上流动
[1.5-4s]  Setup     拉远，她站在雨夜霓虹巷口，背对镜头
[4-6.5s]  Rising    她缓慢转身，镜头跟焦，背景虚化变形
[6.5-9s]  Climax    慢动作拔枪，子弹壳飞过镜头，火光照亮半张脸
[9-10s]  Payoff     黑场 + 字幕 "2087"
```

## 2. 2 秒钩子 + 剧情（适合 6-10 秒广告/抖音）

把 5 段式压缩成 2 段：一个爆炸钩子 + 后续叙事。

```
[0-2s]   Hook      一个违反常识/反差/悬念的镜头
[2-8s]  Story     解释钩子、给到情绪出口
```

**公式**：钩子 = 反差 / 悬念 / 数字 / 痛点

例：
- 反差：穿西装的男人在跳街舞
- 悬念：一只手缓缓推开结了冰的门缝
- 数字：10 亿次观看背后的 10 秒
- 痛点：熬夜加班的你，眼袋正在塌方

---

## 3. 三幕式（适合 30-60 秒微电影）

经典好莱坞结构，适合讲完整小故事。

| 幕 | 时长占比 | 内容 |
|---|---------|------|
| **第一幕 Setup** | 25% | 世界观 + 主角 + 日常 + 激励事件 |
| **第二幕 Confrontation** | 50% | 冲突升级、试探、反转 |
| **第三幕 Resolution** | 25% | 高潮 + 解决 + 新常态 |

**转折点**（punctuation）：
- **第 25% 处**：激励事件（世界被打破）
- **第 50% 处**：中点反转（主角获得新认知）
- **第 75% 处**：黑暗时刻（主角看起来要输了）
- **第 90% 处**：最终高潮
- **结尾**：新常态

AI 视频做 30-60 秒已经是极限，不强求严格三幕，更多是**节奏感上借鉴**。

---

## 4. 冰山叙事（适合艺术/概念短片）

不讲完整故事，只给一个"引子"让观众脑补冰山以下。

```
[给出一个异常的瞬间]
[给出一个线索]
[给出一个暗示，不解释]
```

例：
- 镜头：一扇反复开合的门 → 门后是宇宙 → 一只手从门外伸进来
- 信息量：不解释为什么，让画面本身成为诗

**什么时候用**：
- 艺术短片、概念广告、MV
- 观众会多次回看的内容
- 需要"品味"而不是"看懂"

**什么时候别用**：
- 电商带货（必须清晰）
- 教程/解释类内容

---

## 5. 抖音/Reels 9 秒公式

算法友好型结构，针对竖屏短视频平台优化。

```
[0-1s]  缩略图帧   (用户会看到的封面)
[1-3s]  钩子      (3 秒内没抓住就划走)
[3-6s]  信息密度  (核心 payoff)
[6-8s]  升华/转折 (避免流失)
[8-9s]  Call to action / 悬念
```

**关键**：每 2-3 秒必须有"视觉变化"（镜头切换、角度变化、新元素进入），否则会流失。

---

## 6 选哪个框架？快速决策

| 需求 | 用哪个 |
|------|--------|
| 10-15 秒叙事短片 | **5 段式** |
| 6-10 秒抓眼球广告 | **2 秒钩子 + 剧情** |
| 30-60 秒微电影 | **三幕式** |
| 艺术/概念片，无需说清楚 | **冰山叙事** |
| 抖音/Reels/Shorts 竖屏 | **抖音 9 秒公式** |
| 单一画面氛围片（如壁纸、背景） | **不需要框架**，直接描述画面即可 |

## 通用错误

1. **时长不够还想塞多镜头**：10 秒内超过 3 个运镜切换 = 观众晕
2. **Hook 是静态画面**：90% 情况静态 hook 钩不住人
3. **没有 Payoff**：结尾戛然而止 ≠ 留白，观众会觉得没做完
4. **情绪曲线是一条直线**：必须有起伏，平铺直叙 = 乏味
